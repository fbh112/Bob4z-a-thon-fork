## Analysis: Updates Needed in [`EN/1-LabDiscoverCBSA_EN.md`](EN/1-LabDiscoverCBSA_EN.md)

The lab was written against an older version of Bob. Several concepts, terminology, and UI elements have changed. Here is a structured breakdown, section by section:

### 1. 🔴 Critical — Bob Is Now a Standalone IDE, Not a VS Code Extension

**Where:** [Section 3 – Lab Preparation](EN/1-LabDiscoverCBSA_EN.md:139) (prerequisites list)

**Old text:**
```
- Have IBM Bob Version 2 installed on a workstation (MacOS, Linux, or Windows)
- Have the following extensions installed:
    - Zowe Explorer 3.5.0 (or higher)
    - IBM Z Open Editor 6.6.0 (or higher)
    - IBM Bob Premium Package for Z 3.0.0 (or higher)
    - Mermaid (latest version)
    - Draw.io Integration (latest version)
```

**Issue:** The current Bob is **a standalone IDE application, not an extension**. Per current Bob docs: *"Bob is a standalone IDE application and not an extension."* The old prerequisites describe Bob as if it were a VS Code-based IDE where you install extensions like Zowe Explorer and IBM Z Open Editor alongside it. This entire prerequisites block needs revisiting in the context of the current Bob product architecture.

---

### 2. 🔴 Critical — Built-in Mode Names Have Changed

**Where:** [Section 2 – IBM Bob Premium Package for Z Modes](EN/1-LabDiscoverCBSA_EN.md:57) and throughout all exercises

**Old text in the lab:** The lab describes five modes:
- 🧰 Z Code
- 📐 Z Architect
- ❓ Ask
- 💻 Agent
- 📝 Plan

**Current Bob built-in modes** (from docs):
- **Agent** (write/modify code)
- **Ask** (get explanations)
- **Plan** (planning/design)
- **Advanced**
- **Orchestrator**
- **Code** (referenced in mode-specific rules as `rules-code/`)

**Issue:** The modes "Z Code" and "Z Architect" are **custom modes** provided by the IBM Bob Premium Package for Z — they are not base Bob modes. This itself isn't wrong, but the lab should clearly distinguish that **Ask, Agent, and Plan are Bob built-in modes**, while **Z Code and Z Architect are premium-package custom modes**. The current doc language implies all five are equivalent mode choices within the same tier.

Additionally, throughout exercises the lab instructs users to switch to modes by name (e.g., *"Mode: 💻 Agent"*, *"Mode: 🧰 Z Code"*). The **mode switching UI** has changed: current Bob uses a **dropdown selector to the left of the chat input field**, and the keyboard shortcut `Ctrl`+`.` (Windows/Linux) or `⌘`+`.` (macOS) to cycle through modes. The lab should clarify how to switch modes.
