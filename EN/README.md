# Bob4z-a-thon

A Hackathon to discover the **Bob Premium Package for Z**.

A few labs are offered in this hands-on lab, each exploring a different aspect of the Bob toolchain for IBM Z mainframe applications.

## Labs

* **[1 - Discover CBSA](1-LabDiscoverCBSA_EN.md)** — Discover the CBSA COBOL application. You will be able to inventory the application, explore its architecture, document and query programs or functions of the application. You can then study an evolution of the application with the corresponding implementation plan.
* **[2 - Discover CBSA Global](2-LabDiscoverCBSAGlobal_EN.md)** — Extends the analysis to the application's frontend, enabling you to enrich the business process analysis.
* **[3 - Skill Builder: Refactor](3-LabSkillBuilder-Refactor_EN.md)** — Experiment with creating a skill to refactor existing COBOL programs into separate COBOL modules.
* **[4 - Skill Builder: Code Generation](4-LabSkillBuilder-CodeGen_EN.md)** — Experiment with creating a skill to optimize COBOL program generation, with zCodeScan valication enabled.
* **[5 - Bob Shell](5-LabBobShell.md)** — A quick start guide to using Bob in a terminal environment instead of the chat interface.
* **[6 - Bob MCP](6-LabBobMCPConfiguration.md)** — Shows you how to integrate Bob with a mainframe platform using the zOpenEditor MCP server. _(This lab requires that you have a z/OS environment that you can connect to with Zowe.)_

## Recommended Starting Path

To get started, we recommend focusing on the following labs in order:

* **[1 - Discover CBSA](1-LabDiscoverCBSA_EN.md)** — estimated 3–4h
* **[3 - Skill Builder: Refactor](3-LabSkillBuilder-Refactor_EN.md)** — estimated 1–2h
* **[5 - Bob Shell](5-LabBobShell.md)** — estimated 1–2h
* **[2 - Discover CBSA Global](2-LabDiscoverCBSAGlobal_EN.md)** — estimated 1–2h _(for those interested in the Java frontend)_
* **[4 - Skill Builder: Code Generation](4-LabSkillBuilder-CodeGen_EN.md)** — estimated 1–2h _(for those who want to learn more about ZCodeScan validation)_
* **[6 - Bob MCP](6-LabBobMCPConfiguration.md)** — as it requires an underlying z/OS environment, treat it as reading material if you do not have access.
