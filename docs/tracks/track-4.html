Exercise 5 — Implement the Missing Index

Apply the top DDL recommendation: create the missing PROCTRAN index identified in section 3.1 of the performance report. Bob generates a production-ready JCL.

🧰 Z Code mode — new task

Output: db2jcl/CREI401.jcl — a clustering composite index on PROCTRAN (SORTCODE, NUMBER, DATE DESC, TIME DESC) using the PROCTRAN storage group.
CREATE INDEX IBMUSER.PROCTRAN_IX1
   ON IBMUSER.PROCTRAN (
      PROCTRAN_SORTCODE ASC,
      PROCTRAN_NUMBER   ASC,
      PROCTRAN_DATE     DESC,
      PROCTRAN_TIME     DESC)
   USING STOGROUP PROCTRAN
   CLUSTER;
