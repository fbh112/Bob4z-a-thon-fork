Setup
Environment Setup & Prerequisites
Install IBM Bob IDE with the IBM Bob Premium Package for Z extension, clone the CBSA repository, and prepare your workspace before starting any lab.
~15 min Required for all labs Agent mode
Complete these steps once before starting any lab. The CBSA workspace and extensions are shared across all four lab tracks.
1
Install IBM Bob IDE & the Premium Package for Z

You need IBM Bob IDE (VS Code-based) with the IBM Bob Premium Package for Z extension activated.

1
Download & install IBM Bob IDE
Get the desktop app from bob.ibm.com/download — available for macOS, Windows, and Linux. Accept the invitation email first to activate your IBM ID and team access.
2
Install required VS Code extensions
In Bob IDE, open the Extensions panel (Cmd/Ctrl+Shift+X) and install:
  • IBM Bob Premium Package for Z v3.0.0+
  • IBM Z Open Editor v6.6.0+
  • Zowe Explorer v3.5.0+
  • Draw.io Integration (latest)
  • Mermaid (latest)
3
Activate the Premium Package for Z in Bob settings
Open Bob settings and confirm the Z Code and Z Architect modes appear in the mode selector. If not, verify your Premium Package entitlement in the IBM Bob Administration portal.
2
Clone the CBSA Application Source Code

Create a ~/CBSA directory, open it in Bob IDE, then use Bob to retrieve the source code automatically.

💻 Agent mode
Retrieve the sub-directory named "src/base" in the CBSA directory from the GitHub repository https://github.com/ovallod/Bob4z-a-thon.git and place it in the current workspace folder. Then remove any temporary working directory you would have created.
Bob clones the repo, copies src/base/ into your workspace, and removes the temp directory. You should see: bms_src/ (CICS screens), cobol_copy/ (copybooks), cobol_src/ (29 COBOL programs).
3
About the CBSA Application

The CICS Banking Sample Application (CBSA) is a real banking application simulating bank teller operations. This is the application you will analyze, document, and modernize throughout the labs.

⚠️ Note on AI non-determinism: Bob relies on AI agentics which is non-deterministic. You may see slight differences from the sample results shown in the labs. This is normal — Bob always reaches the goal but may take different paths.
