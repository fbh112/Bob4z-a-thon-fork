Exercise 0 — Define Naming & Organization Rules

Before analyzing code, establish clear conventions for organizing Bob-generated resources. Create Bob rules that define where to store documents, tools, and diagrams.

💻 Agent mode — new task
Create the following Bob rules (file in .bob/rules):
- Documents must be stored in the docs/ directory. Documents specific to a program should be stored in a sub-directory of docs/ using the program name.
- Tools must be stored in the tools/ directory.
- Schemas, drawings and graphs must be stored in graph/ directory.

Document, schemas, drawings and graphs file names must follow these conventions:
-- Prefix: program name (e.g., BNKMENU) or CBSA for the application, or GLOBAL for cross-cutting documents
-- Document type: analysis, archi, docu, inv, plan, spec
-- Format: [PREFIX]-[TYPE]-[description].md
Bob creates .bob/rules/ with naming conventions. If Bob proposes using the create-skill skill, decline it — it is not needed here.
