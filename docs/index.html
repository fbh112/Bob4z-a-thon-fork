Open Your CBSA Folder

Bob needs an open folder to read files, write documentation, and build metadata. Create a dedicated ~/CBSA folder and open it before starting.

File → Open Folder → ~/CBSA
Create an empty CBSA directory in your home folder. In Bob IDE, go to File → Open Folder and select it. Bob will have workspace scope for all lab exercises.
Required extensions
